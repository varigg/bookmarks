# Product Overview

## Bookmark Management Application

A self-hosted Flask web application for managing bookmarks with LLM-powered automatic title and description generation.

### Core Purpose
- **Self-hosted bookmark manager** - Runs on desktop or home server
- **Automatic enrichment** - Uses LLMs to generate titles and descriptions from URLs
- **Multiple input methods** - Browser extension, iOS shortcuts, web interface, REST API
- **Zero manual effort** - Just send URLs, the app handles the rest

### Key Features
- Multi-tag filtering with AND/OR logic
- Favorites support
- Multiple sorting options (newest, oldest, alphabetical, favorites-first)
- Async URL validation
- Automatic backups
- Multiple LLM providers (Perplexity, OpenAI, Anthropic)
- Flexible content extraction (HTML, Markdown, MCP)

### Target Users
- Developers and power users who want a self-hosted solution
- Users who bookmark frequently but don't want to manually write descriptions
- Teams needing a shared bookmark repository

### Integration Points
- Browser extensions (Firefox/Chrome)
- iOS Shortcuts for mobile
- REST API for custom integrations
- Model Context Protocol (MCP) support
